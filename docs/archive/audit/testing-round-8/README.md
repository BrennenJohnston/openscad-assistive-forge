# Testing Round 8 — Full 292-Preset Audit Sweep

> **Date:** 2026-04-02
> **Scope:** Keyguard v75, all 292 presets (desktop CLI + browser)
> **Versions:** OpenSCAD 2021.01 (CGAL), 2026.01.03 Nightly (Manifold), Browser WASM

---

## Purpose

Round 7 established a baseline for 3 default-parameter scenarios plus 3
preset-specific scenarios. Round 8 extends the audit to the **full 292-preset
set** from `keyguard_v75.json`, capturing per-preset reference data from both
the desktop CLI and the browser app.

This data enables the project-native preset parity work (Phases 3–6 of the
[project preset parity plan](../../.cursor/plans/project_preset_parity_40db0611.plan.md))
to classify every remaining mismatch with explicit evidence.

## Running the Audits

### Desktop CLI — Full Sweep

```powershell
# Dry run (validates structure without executing OpenSCAD)
powershell -ExecutionPolicy Bypass -File scripts/desktop-audit.ps1 -PresetSweep -DryRun

# First 5 presets only (quick validation)
powershell -ExecutionPolicy Bypass -File scripts/desktop-audit.ps1 -PresetSweep -BatchSize 5 -BatchIndex 0 -DryRun

# Filter by regex
powershell -ExecutionPolicy Bypass -File scripts/desktop-audit.ps1 -PresetFilter "^iPad 7,8,9 - Fintie" -DryRun

# Full sweep (expect ~6-8 hours for 292 presets × 2 versions)
powershell -ExecutionPolicy Bypass -File scripts/desktop-audit.ps1 -PresetSweep

# Batched sweep (10 presets per batch, batch 0)
powershell -ExecutionPolicy Bypass -File scripts/desktop-audit.ps1 -PresetSweep -BatchSize 10 -BatchIndex 0
```

### Browser Audit

Requires the dev server running and the `.volkswitch/keyguard-test-bundle.zip` fixture.

```powershell
# Full sweep (all presets the browser can see)
npx playwright test preset-audit-sweep

# Filtered sweep (first 5 presets)
$env:BATCH_SIZE = "5"; $env:BATCH_INDEX = "0"; npx playwright test preset-audit-sweep

# Regex filter
$env:PRESET_FILTER = "Fintie"; npx playwright test preset-audit-sweep
```
