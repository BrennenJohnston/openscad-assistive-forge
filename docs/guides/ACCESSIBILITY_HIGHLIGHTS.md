# Accessibility Highlights

A quick tour of the accessibility features in OpenSCAD Assistive Forge. For the full role-based guide, see the [Accessibility Guide](ACCESSIBILITY_GUIDE.md).

## Built for screen readers

- Every control has a real name that screen readers announce
- Status changes are announced as they happen: renders finishing, errors appearing, settings changing
- Dialogs, menus, and panels follow the standard patterns screen readers expect

## Full keyboard operation

- Everything works without a mouse: menus, panels, the 3D preview, and export
- A visible focus ring always shows where you are
- Press the Keys button in the header for the full shortcut reference
- Menus support arrow keys, Escape, and Enter, like desktop applications

## Low vision support

- Dark theme and light theme, following your system setting by default
- A high contrast mode that meets WCAG AAA contrast targets
- Windows High Contrast (forced colors) is supported throughout
- Zoom is never blocked, and the layout keeps working as you zoom in

## Choose how much you see

- Simplified mode shows only the essentials, for a calmer screen
- Standard mode shows the full set of controls
- A guided Assistive Forge interface and a desktop-style Classic interface, switchable at any time

## Motor and voice access

- Buttons and controls meet the 44 by 44 pixel touch target minimum
- Visible control names match their spoken names, so voice control software works naturally
- No control requires dragging; everything has a click or keyboard path

## Calm by default

- Animations respect your reduced motion system setting
- Nothing flashes, auto-plays, or moves without being asked
- Built-in tutorials walk you through the app step by step

## Your data stays yours

- The app runs entirely in your browser
- Your designs are processed on your device and never uploaded
- Works offline after the first visit

## The full guide

The [Accessibility Guide](ACCESSIBILITY_GUIDE.md) covers all of this in depth, organized by role: screen reader users, keyboard-only users, low vision users, voice input users, and switch access users.
