# Classic Interface Guide

OpenSCAD Assistive Forge has two interfaces. This guide describes the Classic interface: what it is, who it is for, and how it differs from the Assistive Forge interface.

## What Classic is

Classic looks and works like the OpenSCAD desktop application. If you already use desktop OpenSCAD, or you are following a book, course, or online tutorial written for it, Classic will feel familiar: the same menus, the same toolbar, and the same window layout.

The layout matches the desktop program:

- Desktop-style menus at the top: File, Edit, Design, View, Window, Help
- An icon toolbar under the menus
- The code editor on the left
- The 3D preview in the middle
- The Customizer panel on the right
- The console at the bottom
- A status bar along the bottom edge

## Who Classic is for

Choose Classic if:

- You already know the OpenSCAD desktop application and want the same layout
- You are following an OpenSCAD tutorial, book, or course written for the desktop program
- You prefer working in a code editor with desktop-style menus

If you are new to OpenSCAD, or you want the most accessible experience, choose the Assistive Forge interface instead. It is a guided interface built for screen readers, keyboard use, and first time users.

## How Classic differs from Assistive Forge

| Feature | Classic | Assistive Forge |
| --- | --- | --- |
| Layout | Desktop OpenSCAD style: editor, preview, Customizer, console | Guided panels with a parameter-first workflow |
| Menus | File, Edit, Design, View, Window, Help (desktop shape) | The same menu bar plus Forge-specific View and File items |
| Appearance | Light desktop look only | Light, dark, and high contrast themes |
| Settings | Edit menu, then Preferences (a desktop-style dialog) | Preferences plus panel controls in the app |
| Devices | Desktop only for now (a mobile version is planned) | Desktop, tablet, and phone |

### The light desktop look

Classic keeps the light desktop look at all times. This is deliberate: Classic exists to match the desktop program exactly, so screenshots, tutorials, and desktop documentation always match what you see.

Dark and high contrast themes work only in the Assistive Forge interface. If you need a dark screen or high contrast colors, use Assistive Forge.

### Preferences

Open Preferences from the Edit menu. The dialog follows the desktop program's shape, with tabs for 3D View, Editor, 3D Print, Advanced, Axes, Buttons, and Keyboard. Tabs that are not available yet say so.

- The 3D View tab holds the desktop color schemes for the 3D preview, such as Cornfield. The color scheme options appear only while you are in the Classic interface, because the schemes color only the Classic 3D view.
- The Advanced tab holds the render engine choice and the app cache controls.

## Switching between interfaces

On a desktop, you can switch between interfaces at any time with the button in the top right corner of the app.

When you switch, your work travels with you:

- Your code stays exactly as you left it
- Your parameter values stay set
- The camera stays where you pointed it

You can switch back and forth as often as you like. Nothing is lost either way.

## Both interfaces make the same models

Classic and Assistive Forge open the same files and produce the same geometry, exports, and prints. The choice is about how you prefer to work, not about what you can make.
