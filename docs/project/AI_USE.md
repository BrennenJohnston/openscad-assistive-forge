# How I use AI tools

I build OpenSCAD Assistive Forge with the help of AI coding assistants. They
draft code, tests and documentation under my direction.

I decide what gets built, review the changes, and check them with the
automated tests and by hand, including with a screen reader. Tactile
dimensions, accessibility wording and anything safety-related are my
decisions.

If you contribute, you may use AI tools too. Say so in your pull request, and
make sure you understand and have tested what you submit.
